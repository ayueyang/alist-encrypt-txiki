## R-44-B：修复前最小复现

**目的**：只让真实适配模块在 Node 环境里处理伪造请求/Worker，先证明失败而非只做静态猜测。**命令**：在 `openwrt-tjs/` 目录运行 `node --test tests/adapter-regression.mjs`（此时四个用例已写、代码尚未修）。

| 用例 | 实际失败（修前） |
|---|---|
| Koa `ctx.status=204,ctx.body=''` | `Response constructor: Invalid response status code 204`；205/304 同类型风险 |
| 定长 raw HTTP 上游 204 | `Response constructor: Invalid response status code 204`；304 带元数据长度也误判正文缺失 |
| 带实体、已知长度的 WebDAV COPY/MOVE | 发出 `Host: 127.0.0.1:5244`，却发出 `Destination: http://127.0.0.1/dav/target`，authority 不同 |
| Worker 报错后的下一次 PRGA | 坏 Worker 的 `postMessage` 抛 `worker has exited`；留下 30 秒定时器导致进程等待 |

**实际摘要**：`tests 4; pass 0; fail 4; duration ≈ 30s`。伪 socket 和假 Worker 均在进程内构造，**没有网络请求、没有 AList 数据写入**。**结论：确认适配异常路径缺陷；不是目标运行时上的复现**。
